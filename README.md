# E-Brix

E-Brix merupakan sebuah sistem berbasis multi-platform yang dirancang untuk membantu proses pemantauan dan analisis tingkat kematangan tebu secara digital dan terintegrasi. Sistem ini memanfaatkan teknologi mobile dan web untuk mengumpulkan, mengelola, serta memvisualisasikan data kadar gula (brix) secara real-time.

Pada sisi perangkat mobile (Android dan iOS), E-Brix difokuskan sebagai alat akuisisi data di lapangan. Pengguna dapat mengambil foto menggunakan refraktometer sebagai media pendukung pengukuran, kemudian sistem akan mencatat informasi penting seperti nilai brix, lokasi geografis (latitude dan longitude), serta waktu pengambilan data (timestamp). Fitur ini memungkinkan proses pencatatan data menjadi lebih cepat, akurat, dan terdokumentasi dengan baik.

Sementara itu, pada sisi web, E-Brix berperan sebagai pusat monitoring dan analisis data. Data yang telah dikumpulkan dari perangkat mobile akan ditampilkan dalam bentuk visualisasi yang informatif, seperti grafik perkembangan nilai brix, distribusi data, serta heatmap berbasis lokasi untuk melihat persebaran tingkat kematangan tebu di berbagai area lahan. Hal ini membantu pengguna dalam melakukan analisis kondisi tanaman secara lebih komprehensif dan mendukung pengambilan keputusan yang lebih tepat.

Secara keseluruhan, E-Brix mengintegrasikan proses pengambilan data di lapangan dengan sistem analitik berbasis web, sehingga menciptakan solusi yang efisien, terstruktur, dan berbasis data dalam menentukan tingkat kematangan tebu.
